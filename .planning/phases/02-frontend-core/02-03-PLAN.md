<tasks>

<task type="auto">
  <name>Task 1: Implement Dual-Handle Timeline</name>
  <files>index.html</files>
  <action>
    Create a custom timeline component below the video preview:
    1. A horizontal track representing 100% of video duration.
    2. Two draggable teal handles for START and END.
    3. Handles should be constrained within the track and START &lt;= END.
    4. Implement mouse and touch events for dragging.
    5. Display floating timecodes (MM:SS) above each handle.
  </action>
  <verify>
    - Handles can be dragged independently.
    - START handle cannot go past END handle.
    - Timecodes match the position in the video.
  </verify>
  <done>Timeline is interactive and displays correct timecodes.</done>
</task>

<task type="auto">
  <name>Task 2: Sync Video with Scrubbing</name>
  <files>index.html</files>
  <action>
    Wire the timeline handles to the &lt;video&gt; element:
    1. When a handle is being dragged, update video.currentTime to that handle's position.
    2. Ensure smooth seeking (use requestAnimationFrame or throttle events if needed).
    3. Update App.config.start and App.config.end as handles move.
  </action>
  <verify>
    - Video seeks in real-time as handles are moved.
  </verify>
  <done>Visual feedback from the video matches the timeline selection.</done>
</task>

<task type="auto">
  <name>Task 3: Implement Range Presets</name>
  <files>index.html</files>
  <action>
    Add pill buttons for quick selection:
    1. "First 2 Minutes": Sets START=0, END=min(120, duration).
    2. "First 5 Minutes": Sets START=0, END=min(300, duration).
    3. "Full Video": Sets START=0, END=duration.
    Clicking a preset should update handles, video seeking, and App state.
  </action>
  <verify>
    - Clicking presets updates handles correctly.
    - Full Video selects the entire duration.
  </verify>
  <done>User can quickly select common ranges.</done>
</task>
