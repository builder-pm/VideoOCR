  <files>index.html</files>
  <action>
    Implement the 'Upload Panel' in the main content area per UI-SPEC:
    - Dashed border zone with cloud icon.
    - Handle 'dragover', 'dragleave', and 'drop' events for visual feedback.
    - Implement click-to-upload using a hidden &lt;input type="file"&gt;.

<task type="auto">
  <name>Task 2: Integrate Upload API</name>
  <files>index.html</files>
  <action>
    Implement the 'API.upload' function and wire it to the dropzone:
    1. Show a loading state/spinner during upload.
    2. Use FormData to send the file to '/upload'.
    3. On success, store sessionId and metadata in 'App' state.
    4. Handle errors (e.g., file too large, invalid format) by showing a toast or alert.
  </action>
  <verify>
    - Uploading a valid video returns a session ID (check network tab).
    - UI shows spinner during upload.
  </verify>
  <done>Videos are successfully uploaded to the backend.</done>
</task>

<task type="auto">
  <name>Task 3: Display Video Preview & Metadata</name>
  <files>index.html</files>
  <action>
    After upload, transition from the dropzone to the preview state:
    1. Show a &lt;video&gt; element with the uploaded video (can use URL.createObjectURL for local preview or fetch if needed, but local is faster).
    2. Display metadata badges: Duration (MM:SS), Resolution, and Native FPS.
    3. Store video dimensions and duration in App state for later calculations.
  </action>
  <verify>
    - Video preview is visible and playable.
    - Duration, Resolution, and FPS are displayed correctly.
  </verify>
  <done>User can see the uploaded video and its properties.</done>
